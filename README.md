# 🧶 코코아뜰리에 (Coco Atelier) - 뜨개인 전용 도안 체크 & 관리 웹앱

뜨개인들이 도안을 한 줄 한 줄 편하게 체크하고, 여러 장의 도안 파일(`PDF`, `JPG`, `PNG`)을 순서대로 텍스트로 변환해 등록하며, 나만의 뜨개 메모와 참고 링크를 보관할 수 있는 웹 애플리케이션입니다.

---

## ✨ 주요 기능 요약

1. **간편 로그인 (`아이디: 이름`, `비밀번호: 숫자`)**
   - 별도의 복잡한 가입 절차 없이 **이름(닉네임)**과 **숫자로만 이루어진 비밀번호**로 로그인 및 자동 등록됩니다.
2. **홈 화면 3대 핵심 메뉴**
   - 📋 **뜨개질 목록** / ✍️ **뜨개질 등록** / 📎 **뜨개질 첨부파일**
3. **뜨개질 목록 & 한 줄 체크 모드**
   - **내가 올린 뜨개질 목록**과 **타인이 공용으로 올린 뜨개질 목록**을 탭으로 구분하거나 한눈에 볼 수 있습니다.
   - 도안을 클릭해 들어가면 **한 줄씩 클릭하여 완료 체크(✓)**를 할 수 있고, **다음에 뜰 줄이 자동으로 강조**됩니다.
   - **[체크 초기화]** 버튼으로 언제든 처음부터 다시 뜰 수 있습니다.
   - **빠른 단수·코수 카운터**와 **기타 개인 메모란**(몇 줄 몇 코까지 떴는지 기록)이 제공됩니다.
   - 🔒 **개인 프라이버시 보장**: 타인이 공용으로 올린 도안을 클릭해 체크하고 메모하더라도, **체크 표시와 메모는 오직 로그인한 본인에게만** 보입니다.
4. **뜨개질 등록 (다중 파일 순서 정렬 & 텍스트 자동 추출 + 수동 입력)**
   - `PDF`, `JPG`, `PNG` 파일을 여러 개 업로드하고 **[▲ 위로] / [▼ 아래로]** 버튼으로 순서를 맞춘 뒤 **[순서대로 텍스트 읽어오기]**를 누르면 브라우저에서 무료로 텍스트를 추출(`PDF.js` + `Tesseract.js` 한국어/영어 OCR)하여 줄 단위 체크리스트 형식으로 자동 변환합니다.
   - 텍스트를 직접 복사/붙여넣기(복붙)하여 수동으로 등록하거나 추출된 텍스트를 자유롭게 편집할 수 있습니다.
   - **미리보기 그림 최적화**: 첫 번째 파일에서 자동으로 썸네일을 만들거나 직접 사진을 올릴 수 있으며, 고화질 원본을 그대로 올리지 않고 **Canvas 압축 기술로 10~25KB 수준의 저용량 이미지로 자동 최적화**하여 저장합니다.
5. **뜨개질 첨부파일 (링크 보관함)**
   - 참고할 유튜브 영상, 블로그 도안, 실 구매처 링크를 붙여넣으면 **그대로 저장**되고 **나만의 링크 목록**에서 사이트별로 깔끔하게 모아볼 수 있습니다.

## 🔥 Firebase 연결 방법

1. [Firebase Console](https://console.firebase.google.com/)에 접속해 새 프로젝트를 만듭니다.
2. 프로젝트 개요 화면에서 **웹(`</>`) 앱 추가**를 클릭하고 `firebaseConfig` 설정값을 복사합니다.
3. 왼쪽 메뉴에서 **빌드 > Firestore Database**로 이동해 **데이터베이스 만들기**(테스트 모드 시작 권장)를 완료합니다.
4. 설정값을 적용하는 방법 (택 1):
   - **방법 A (코드에 직접 입력)**: [`js/firebase-config.js`](./js/firebase-config.js) 파일을 열어 `window.DEFAULT_FIREBASE_CONFIG` 안에 복사한 키들을 붙여넣고 저장합니다.
   - **방법 B (앱 화면에서 바로 입력)**: 웹앱 상단 우측의 **`로컬 저장소 (Firebase 설정 가능)`** 배지를 클릭하여 열리는 창에 `firebaseConfig` JSON을 붙여넣고 **[연결 저장 및 적용]**을 누릅니다.

## 🌐 GitHub 업로드 및 Render 배포 방법

1. **GitHub 저장소(Repository)에 코드 올리기**
   - GitHub에서 새 Repository를 생성한 뒤 이 폴더 안의 모든 파일(`index.html`, `css/`, `js/`, `render.yaml`, `package.json` 등)을 업로드합니다.
2. **Render에서 무료 배포하기**
   - [Render 대시보드](https://dashboard.render.com/)에 로그인 후 **New +** → **Static Site**를 선택합니다.
   - 방금 올린 GitHub Repository를 연결합니다.
   - 설정을 아래와 같이 입력합니다 ([`render.yaml`](./render.yaml)이 포함되어 있어 자동 인식됩니다):
     - **Build Command**: *(비워두기)*
     - **Publish Directory**: `.`
   - **Create Static Site** 버튼을 누르면 1분 내로 배포가 완료되어 인터넷 주소(`https://...onrender.com`)가 생성됩니다!
